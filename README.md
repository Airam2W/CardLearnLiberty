# CardLearnLiberty (CCL)

CCL is a website that you can create flashcard for study and memorize what you want.
For example, if you want study vocabulary for any lenguaje. You can create a flashcard, like:  
한국 <--> Korea
You can login with your Gmail account, and create, view and edit your set of flashcard for you study.

---

## Why this project (CLL) was created?

When I was studying Korean in my free time, I wanted an app or website that help me study Korean vocabulary, and others apps were complicated and not fasters. I just wanted a simple app for study using flashcard, and I created this website called CardLearnLiberty (CLL).

---

## Good things about this project (CLL)

- Can you use CLL in laptop, PC or any mobile (Android, IOS) because it is a website.
- CCL have a simple login (Google Account) and is easy to use.
- Can you create a lot of sets of flashcard and study it.

---

## Features of CLL

- Simple interface.
- Easy to use.
